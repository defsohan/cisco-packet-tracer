# Advanced Network

**Status:** 🔜 Planned

## Focus

Multi-site network scenarios building on the fundamentals covered elsewhere in this repo — planned to include site-to-site connectivity, redundancy, and more complex real-world requirements.

## Planned Scope (subject to change as this project develops)

- [ ] Multi-site topology (2+ sites connected via WAN link)
- [ ] Redundancy (e.g. HSRP/dual routers, redundant trunk links with STP)
- [ ] IPv6 addressing alongside IPv4
- [ ] Combined use of everything from earlier projects (VLANs, OSPF, NAT, ACLs, port security) in one larger scenario

This project will be built once the earlier project folders in this repo are complete and verified.
